# Расписание занятий

Менеджмент в образовании · группа 403-61м · осенний семестр 2026-2027.

Одностраничный сайт без сборки: всё лежит в `index.html`.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий и загрузите в него все файлы из этой папки.
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## Как обновлять
- Преподаватели: блок `teachers` в конце `index.html`.
- Диапазоны недель: `numeratorRanges` и `denominatorRanges` там же.
- Ссылки на Телемост: атрибуты `href` у строк занятий.
